# HAJI (gambaran umum, aturan per November 2026)

- Haji 1448 H perkiraan wukuf Arafah ± 15–16 Mei 2027. Rangkaian utama 8–13 Dzulhijjah: Mina (tarwiyah) → Arafah (wukuf) →
  Muzdalifah (mabit) → Mina (lempar jumrah, mabit) → thawaf ifadhah & sa'i → thawaf wada'.
- Haji wajib memakai visa haji. Visa umrah/turis/kunjungan TIDAK bisa untuk haji; razia & denda berat untuk haji tanpa izin.
- Jalur jamaah Indonesia:
  · Haji reguler (kuota pemerintah, antre bertahun-tahun).
  · Haji khusus (ONH plus) lewat PIHK resmi, antre lebih pendek.
  · Haji mujamalah/furoda (visa undangan kerajaan Saudi, tanpa antre, biaya tinggi, kepastian visa sering mepet) — sesuai UU,
    wajib lewat PIHK resmi.
- Penduduk Saudi (iqomah) bisa haji lewat paket domestik di Nusuk/haj.gov.sa.
- Menjelang haji, Makkah ditutup untuk non-pemegang izin haji/izin masuk sekitar ± 1 bulan sebelumnya. Umrah berhenti (lihat tanggal di file aturan umrah).
- Layanan terkait kita: transport & handling jamaah sebelum/sesudah haji, ziarah Madinah. Paket haji spesifik → handoff ke admin.
